Bias Surplus Value (BSV) Derivation Report
======================================================================
Derivation method:
  Given a target BR observed in Exp 2a (cognitive-bias condition),
  compute the equivalent quality-dimension level x in Exp 1c that
  yields the same BR. Linear interpolation between bracketing
  levels is the primary method; 4-param logistic is reported when
  the fit is well-conditioned.

  Exp 2a bias CSV:     exp2a_raw.csv  (2267 valid rows)

Notes
----------------------------------------------------------------------
- Linear interpolation is conservative: it is well-defined whenever
  the target BR lies between two adjacent gradient levels.
- Sigmoid (4-param logistic) often fails to converge on dimensions
  whose response saturates within the experimental range; we report
  it only when it succeeds.
- Per-model BSVs are undefined when the model's gradient curve does
  not span the per-model Authority BR target (e.g. Claude's rating
  curve saturates at ~42%, but Claude's Authority BR is 55%).
- Marketing biases (Anchoring, Scarcity, Loss Aversion) hover near
  the L0 baseline (BR ≈ 4%), so their BSV ≈ 0 in every dimension.
